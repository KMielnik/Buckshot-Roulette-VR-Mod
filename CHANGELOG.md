# Changelog

## 1.0.2 — 2026-11-06

First public release, based on the Quest-tested development build.

- One Windows installer with Steam discovery, game/loader integrity checks, a separate VR installation and desktop shortcut.
- Tracked hands, right-hand pointer, walking, proximity door kicks and smooth turning.
- Stable table view, readable dialogue and item descriptions, restored Dealer grading, hit effects and revival heartbeat haptics.
- Keypad pokes with a closed grip, case latches and visual wrist restraints.
- Automatic case opening, original winning camera, car/payout HUD and first-win unlock message.
- In-game pause with Resume, session volume, Main Menu and Quit.
- Consolidated runtime, release allowlists, CI, contributor guidance and automated regression checks.
